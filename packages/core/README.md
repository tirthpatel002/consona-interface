# `@consona/interface-core`

Substrate, optical theme, `InterfaceProvider`, and foundation components.

```bash
npm install @consona/interface-core
```

```ts
import { Button, InterfaceProvider } from '@consona/interface-core'
import '@consona/interface-core/styles.css'
```

Prefer this package when you do not need maps, charts, DnD, media, etc.  
Other modules (`@consona/interface-dnd`, `@consona/interface-media`, …) depend on core.

See the [monorepo README](../../README.md).
